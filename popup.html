🚀 Bắt đầu

  1. Vào shopgmail9999.com → đăng nhập → vào Thông tin tài khoản → copy API Key.
  2. Mở tab 💰 Mua mới → paste API key → click Save.
  3. Click 🔄 Tải danh sách sản phẩm → chọn sản phẩm + số lượng → 💳 Mua ngay.
  4. Nếu bật Auto-import (mặc định) → cookie tự import + mở tab accounts.google.com đã login.

⚠️ Setup 1 lần — TẮT DBSC

Bắt buộc để cookie không bị Google sign-out:

  1. Mở chrome://flags
  2. Search: Bound Session Credentials → set Disabled
  3. Click Relaunch

📝 Pre-fill API key qua config.json

Để distribute extension cho nhiều máy mà không cần gõ API key lần đầu:

  1. Mở folder extension → file config.json
  2. Paste API key vào field "apikey"
  3. Set "autoImport" / "autoRetry" / "retryDelaySeconds" nếu muốn default khác
  4. Reload extension trong chrome://extensions
{
  "apikey": "PASTE_KEY",
  "autoImport": true,
  "autoRetry": false,
  "retryDelaySeconds": 3
}

Lưu ý: config.json chỉ load khi chrome.storage.local chưa có key. Để force load lại: xoá storage qua chrome://settings/cookies → search extension → Remove.

Extension expose API qua chrome.runtime.onMessageExternal cho các trang web matching:

  • *://shopgmail9999.com/*
  • http://localhost/*
  • http://127.0.0.1/*

ActionParamsResponse

💻 Ví dụ JavaScript (chạy trong console của shopgmail9999.com)

// 1. Set API key
chrome.runtime.sendMessage(
  "EXT_ID",
  { action: "setApiKey", apikey: "your-key" },
  resp => console.log(resp)
);

// 2. Mua + auto-import + auto-retry
chrome.runtime.sendMessage(
  "EXT_ID",
  {
    action: "buyProduct",
    productId: 4,
    quantity: 1,
    autoImport: true,
    autoRetry: true,
    retryDelaySeconds: 5,
    maxRetries: 0   // 0 = unlimited
  },
  resp => {
    console.log("Attempts:", resp.attempts);
    console.log("Account:", resp.firstAccount);
  }
);

🐍 Ví dụ Selenium Python

from selenium import webdriver
from selenium.webdriver.chrome.options import Options

opts = Options()
opts.add_argument("--load-extension=/path/to/cookie-importer")
driver = webdriver.Chrome(options=opts)

EXT_ID = "EXTENSION_ID"
driver.get("https://shopgmail9999.com/")

# Mua + tự retry tới khi có hàng + tự import cookie
result = driver.execute_async_script("""
  const cb = arguments[arguments.length - 1];
  chrome.runtime.sendMessage(arguments[0], {
    action: "buyProduct",
    productId: 4, quantity: 1,
    autoImport: true, autoRetry: true,
    retryDelaySeconds: 5
  }, resp => cb(resp));
""", EXT_ID)

print(result["firstAccount"])  # {email, password}
# Driver đã được set cookie Gmail → mở gmail.com là login luôn

❓ Troubleshooting

  • "chrome.runtime is undefined" trên page → page không matching externally_connectable. Phải vào shopgmail9999.com hoặc localhost.
  • Google sign-out sau import → chưa tắt DBSC flag, hoặc đang sync Chrome với account khác.
  • Cookie skip nhiều → file cookie không đúng format Cookie-Editor. Xem placeholder textarea tab Import.
  • Mua fail liên tục → check số dư + sản phẩm còn stock + API key đúng.
